# RxOne Scanner (หน้าสแกนด้วยกล้องมือถือ)

หน้าเว็บในระบบหลักเปิดกล้องมือถือไม่ได้ เพราะทำงานใน iframe ของ Google จึงมีหน้านี้แยกไว้วางบน GitHub Pages ฟรี

## ใช้ทำอะไร

- **นับสต็อก**: เลือกรอบตรวจนับ ยิงป้ายตำแหน่ง แล้วยิงกล่องยาหรือสติกเกอร์ล็อต หลายเครื่องนับพร้อมกันได้
- **ตรวจเช็คด่วน**: ยิงกล่องยา ดูคงเหลือทุกคลัง ล็อต และวันหมดอายุ
- **จับคู่กับคอม**: บนคอมกดปุ่มรูปมือถือบนแถบด้านบน แล้วสแกน QR ด้วยมือถือ ทุกบาร์โค้ดที่ยิงจากมือถือจะไปโผล่ในหน้าที่เปิดอยู่บนคอม เช่น หน้ารับยา หรือหน้าจ่ายยา

## วางบน GitHub Pages (ครั้งเดียว ประมาณ 10 นาที)

1. สมัครหรือเข้าสู่ระบบ github.com
2. กด New repository ตั้งชื่อ เช่น `rxone-scanner` เลือก Public แล้วกด Create
3. กด uploading an existing file แล้วลากไฟล์ 3 ไฟล์ในโฟลเดอร์นี้ (`index.html`, `app.js`, `config.js`) ไปวาง กด Commit changes
4. ไปที่ Settings > Pages ตรง Branch เลือก `main` และ `/ (root)` กด Save
5. รอ 1-2 นาที จะได้ที่อยู่แบบ `https://ชื่อบัญชี.github.io/rxone-scanner/`
6. ในระบบหลัก ไปที่ ตั้งค่า > Scanner มือถือ วางที่อยู่นี้แล้วกดบันทึก

## ใช้งานครั้งแรกบนมือถือ

- วิธีง่ายสุด: บนคอมกดปุ่มรูปมือถือ แล้วใช้กล้องมือถือสแกน QR หน้า Scanner จะรู้ที่อยู่ระบบให้เอง
- หรือเปิดที่อยู่ GitHub Pages ในมือถือ แล้ววางที่อยู่เว็บแอป (ลงท้าย /exec) ที่แสดงในหน้า ตั้งค่า > Scanner มือถือ
- เข้าสู่ระบบด้วยชื่อผู้ใช้เดียวกับระบบหลัก อนุญาตให้ใช้กล้องเมื่อเบราว์เซอร์ถาม

## หมายเหตุ

- อ่านบาร์โค้ด EAN-13, Code 128, QR และ GS1 DataMatrix ด้วยตัวอ่านในเบราว์เซอร์ ถ้าเบราว์เซอร์ไม่มี จะใช้ ZXing แทน (Safari บน iPhone ใช้ ZXing)
- หน้านี้ไม่เก็บข้อมูลยาหรือผู้ป่วยไว้ในเครื่อง เก็บแค่ที่อยู่ระบบและรหัสเข้าใช้งาน
- ถ้าเปลี่ยนที่อยู่เว็บแอป (ทำการทำให้ใช้งานได้ใหม่แบบ URL ใหม่) ให้กด ออก แล้วกด เปลี่ยนที่อยู่เว็บแอป
- ไม่อยากใช้ GitHub: ใช้เครื่องยิงบาร์โค้ด Bluetooth แบบ 2D หรือแอปสแกนที่ส่งค่าเป็นคีย์บอร์ดไปที่คอมแทนได้
